# Contributing to EUROPA

Contributions, bug reports and small test scenes are welcome.

1. Discuss substantial gameplay or geographic changes in an issue first.
2. Create a branch from main; keep changes small, documented and testable.
3. Run `pnpm typecheck` and `pnpm build` before opening a PR.
4. Never commit `node_modules`, credentials, or unlicensed assets.
5. Document sources and licenses for geographic data, textures, sounds and 3D models.
6. All contributions to the game code are submitted under GPL-3.0. Only contribute code you have rights to license.

OpenStreetMap data is © OpenStreetMap contributors, licensed under ODbL 1.0. Attribute the source and review database-share-alike requirements for any imported/derived data. Code GPL licensing does not override data and media licenses.
